# Federated Matrix Factorization for Recommendation

This repository is a research prototype for evaluating matrix-factorization recommender systems in federated learning settings. It partitions user/item ratings among simulated parties, trains collaborative models, evaluates rating predictions, and can run a membership-inference analysis against trained models.

> **Research software:** this code has not been independently audited. Enabling differential-privacy-related options does not, by itself, establish a formal privacy guarantee. Do not use it to protect real user data without reviewing and validating the implementation.

## What is included

- **Federated settings:** vertical (VFL), horizontal (HFL), and local (LFL) data partitioning.
- **SGDMF experiments:** `VFL-SGDMF`, `HFL-SGDMF`, and `LFL-SGDMF`, with configurable privacy parameters and per-user rating trimming.
- **Baseline algorithms:** FedAvg, FedProx, and FedADMM.
- **Evaluation:** MSE, RMSE, MAE, R², explained variance, training-loss plots, and communication statistics where available.
- **Optional privacy analysis:** shadow-model membership inference and a risk summary.
- **Datasets:** MovieLens 1M and 10M are configured in the runner; an IID synthetic dataset can be generated by the code.

The implementation is organized as follows:

| File | Purpose |
| --- | --- |
| `main.py` | Dataset management, experiment configuration and orchestration, evaluation, and result export |
| `data_partitioner.py` | Vertical, horizontal, and per-user rating partitioning |
| `party.py`, `coordinator.py` | Simulated federated parties and coordinator |
| `sgdmf_vfl.py`, `sgdmf_hfl.py`, `sgdmf_lfl.py` | SGDMF implementations for each federated setting |
| `fed_avg.py`, `fed_prox.py`, `fed_admm.py` | Federated baseline implementations |
| `differential_privacy.py` | Noise, sensitivity, trimming, and privacy-accounting helpers |
| `matrix_factorization.py` | Centralized matrix-factorization implementation |
| `evaluator.py` | Metrics, comparisons, and plots |
| `test_vfl_no_noise.py` | Standalone VFL diagnostic comparing training with and without noise |

## Requirements

Python 3.10 or later is recommended. Install the third-party packages used by the project:

```bash
python -m venv .venv
```

Activate the virtual environment, then install:

```bash
python -m pip install numpy pandas matplotlib scipy scikit-learn seaborn
```

On Windows, activate the environment with `.venv\Scripts\activate`; on macOS/Linux, use `source .venv/bin/activate`.

## Dataset setup

Run commands from the repository root. The runner expects comma-separated rating files with user, item, and rating columns (for example, `userId,movieId,rating`) at:

```text
data/
├── MovieLens1M/ratings.csv
└── MovieLens10M/ratings.csv
```

The source files provided by GroupLens use the `ratings.dat` format rather than this repository's CSV layout. Prepare or convert them to the expected CSV format before running an experiment. Dataset downloads and terms are available from the [MovieLens dataset page](https://grouplens.org/datasets/movielens/).

`MovieLens25M` has a configuration entry but no corresponding dataset is included here, and `BookGenome/ratings.csv` is not currently registered as a dataset in the runner. If a configured dataset file is missing, the current loader silently generates synthetic data instead; check the logs and data paths so experiments do not accidentally run on synthetic ratings.

## Run an experiment

Running the script directly starts the full comparative experiment configuration in `main.py`. It uses MovieLens 10M, launches multiple worker processes, runs many algorithm/party/privacy combinations, and enables membership-inference attacks; it can take a long time and use substantial memory and CPU.

For a small smoke run, call the experiment runner explicitly:

```python
from main import (
    AttackerConfig,
    DatasetManager,
    ExperimentConfig,
    ExperimentRunner,
)

runner = ExperimentRunner(DatasetManager())
result = runner.run_experiment(
    ExperimentConfig(
        experiment_id="synthetic-vfl-smoke",
        algorithm="VFL-SGDMF",
        setting="VFL",
        dataset="synthetic",
        n_parties=2,
        embedding_dim=8,
        T=2,
        T_prime=2,
        learning_rate=0.01,
    ),
    AttackerConfig(run_attacks=False),
)

print(result["eval_results"]["rmse"])
```

Save that snippet as a Python file in the repository root and run it with the configured environment. The synthetic dataset is generated by the project; no MovieLens data is required for this example.

The VFL diagnostic can be run separately when a prepared MovieLens 1M CSV is available:

```bash
python test_vfl_no_noise.py
```

This is a standalone script, not a pytest test suite, and it performs two training runs.

## Outputs

Experiments create cache files and reports/plots in directories such as `cache/`, `plots/`, `validation_results/`, `inference_attacks/`, and `results/`. These are generated artifacts and are not source files. The comparative runner also exports timestamped CSV and pickle summaries to `results/`.
